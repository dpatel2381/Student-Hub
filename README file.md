**README file**

**Student Hub Portal**



**Overview:**

Student Hub is a semester-long project designed to unify student resources, announcements, events, and personal dashboards into one portal.



**Features:**

\- Authentication (Login/Register)

\- Dashboard with personalized info

\- Calendar \& Events

\- Announcements \& Resources

\- Profile management

\- Contact \& FAQ



**Tech Stack:**

\- HTML, CSS, JavaScript (Static version)

\- Future scope: Backend integration (Node.js, MongoDB)



**Setup:**

1\. Clone the repository

2\. Open index.html in browser

3\. Navigate through static pages
